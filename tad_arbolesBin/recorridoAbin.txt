Recordar las dos formas de recorrer un árbol, por profundidad/altura, o bien en anchura.


De la primera forma se puede hacer de forma recursiva, o implementar una pila para hacerlo de
forma iterativa, pudiendose recorrer de 3 formas distintas preorden, inorden y postorden ... Nos
será util implementar una forma u otra dependiendo lo que deseemos hacer (crear, destruir árboles ... )

- PREORDEN:
procesar(n, A);
preordenAbin(A.hijoIzqdo(n), A, procesar);
preordenAbin(A.hijoDrcho(n), A, procesar);

- INORDEN:
inordennAbin(A.hijoIzqdo(n), A, procesar);
procesar(n, A);
inordennAbin(A.hijoDrcho(n), A, procesar);

- POSTORDEN:
postordenAbin(A.hijoIzqdo(n), A, procesar);
postordenAbin(A.hijoDrcho(n), A, procesar);
procesar(n, A);

ITERATIVA: usando while o do-while

Pila<typename Abin<T>::nodo> P; // Pila de nodos de árbol binario.P.push(n);
    while (!P.vacia()){
        n = P.tope(); P.pop();
        procesar(n, A);
        if (n != Abin<T>::NODO_NULO){
            P.push(A.hijoDrcho(n));
            P.push(A.hijoIzqdo(n));
    }
}
